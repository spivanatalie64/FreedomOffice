    A Microsoft Office Fluent Design-inspired icon theme for FreedomOffice.

    Design by: spebdesigner (natalie's web design twin)
    Built for: FreedomOffice - the free and open source office suite

    This theme provides a visual experience that mirrors Microsoft Office's
    Fluent Design language, including:

    - Neutral gray icon palette (#424242 default, #A0A0A0 disabled)
    - Clean, minimal monoline icon style (24x24 base, 2px stroke)
    - Consistent with MS Office 365+ visual language
    - Accessible contrast ratios (WCAG AA compliant)
    - Light and dark mode support

    Color Palette Reference:
        Icon Default:   #424242
        Icon Disabled:  #A0A0A0
        Icon Active:    #1A73E8
        Icon White:     #FFFFFF
        Chrome BG:      #F3F3F3
        Tab Bar BG:     #FAFAFA
        Title Bar BG:   #2B579A (Writer) / #217346 (Calc) / #D2422F (Impress)
        Status Bar BG:  #F3F3F3
        Accent Blue:    #1B73E8
        Accent Green:   #107C10
        Accent Orange:  #D83B01
        Accent Purple:  #5C2D91

    File Locations:
        cmd/       - Command icons (24x24 SVGs)
        cmd/32/    - Large command icons (32x32 SVGs)
        status/    - Status indicator icons
        brand/     - Application brand icons (splash, about)
        brand/shell/ - Shell integration icons
        color_scheme/ - Color override files for SVG icons
        res/       - Additional resources
