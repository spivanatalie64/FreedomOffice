# FreedomAI Skill

FreedomAI is integrated via opencode. When invoked, it can:

- Write and edit documents
- Analyze spreadsheet data
- Generate presentation content
- Create formulas and macros
- Provide feature guidance
- Automate workflows

## Usage
Call @FreedomAI in any conversation to get AI assistance with FreedomOffice tasks.
