## Fair Use of Trademarks for Compatibility Descriptions

FreedomOffice accurately describes its compatibility with Microsoft Office
file formats and its user interface design for the purpose of:

1. **Informing users** that FreedomOffice can open, edit, and save
   Microsoft Office file formats (.docx, .xlsx, .pptx)
2. **Helping users transition** from Microsoft Office by providing a
   familiar user interface
3. **Accurate product description** in marketing and documentation

These uses constitute nominative fair use of Microsoft's trademarks, as
they are used solely to identify the compatible products and are not used
in a way that suggests sponsorship or endorsement by Microsoft.
